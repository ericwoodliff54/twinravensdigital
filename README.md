# Twin Ravens Digital LLC — Landing Page Package

This archive contains everything you need to launch the official web presence for **Twin Ravens Digital LLC** (`twinravensdigital.com`).

---

## 📦 What's Included

1. **`index.html`**: The complete, standalone landing page.
   - Built with modern Tailwind CSS and Norse-inspired typography.
   - Fully responsive across desktop, tablet, and mobile.
   - Self-contained with the custom Twin Ravens emblem embedded directly (no broken image paths).
   - Features the corporate introduction, portfolio highlight (Rakka), core capabilities, and interactive client consultation modal.
2. **`twin_ravens_logo.jpg`**: High-resolution standalone emblem featuring Huginn & Muninn with luminous cyan knotwork, central Gungnir spear divider, and antique gold Norse typography on black.
3. **`email_signature.html`**: Ready-to-copy HTML signature template for Google Workspace / Gmail.

---

## 🚀 Instant Deployment (1-2 Minutes)

### Option A: Cloudflare Pages (Recommended - Free & Fast)
1. Log in to [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Navigate to **Workers & Pages** > **Create application** > **Pages** > **Upload assets**.
3. Drag and drop the `index.html` file (or this unzipped folder).
4. Click **Deploy site**.
5. Under **Custom domains**, connect `twinravensdigital.com`. Cloudflare automatically provisions free SSL/TLS certificates and global CDN caching.

### Option B: GitHub Pages / Vercel / Netlify
- **GitHub Pages:** Commit `index.html` to a repository and enable Pages in repository settings under the `main` branch.
- **Vercel / Netlify:** Drag and drop this folder onto the Vercel or Netlify dashboard to deploy instantly.

### Option C: Traditional Web Hosting (cPanel / Apache / Nginx)
- Upload `index.html` and `twin_ravens_logo.jpg` directly to your server's `public_html` or web root directory.
